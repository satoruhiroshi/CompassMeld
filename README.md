# CompassMeld

Geo-aware data fusion platform leveraging real-time spatial processing and auto-scaling engine capabilities.

CompassMeld is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Geo-aware data fusion platform leveraging
- real-time spatial processing and auto-scaling
- engine capabilities

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CompassMeld.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure CompassMeld, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
